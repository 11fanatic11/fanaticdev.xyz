MediaControl on Linux

MediaControl shows the music or video you are playing (title, artist, album cover, progress bar, play/pause, skip and back) on the Minecraft pause menu and main menu.

On Windows it works out of the box. On Linux it needs one small program installed, playerctl, plus a media player that supports MPRIS (the standard Linux media-control interface).

On this page What you need 1. Install playerctl 2. Check that it works 3. Start Minecraft Flatpak launchers Troubleshooting Good to know

What you need

  • Minecraft Java with the MediaControl mod installed (Fabric, NeoForge or Forge).
  • playerctl installed on your system.
  • A media player that supports MPRIS. Spotify, VLC, Rhythmbox, Firefox, Chrome and most other players do.

1. Install playerctl

Run the command for your distribution:

DistributionCommand
Ubuntu / Debian / Linux Mintsudo apt install playerctl
Fedorasudo dnf install playerctl
Arch / Manjarosudo pacman -S playerctl
openSUSEsudo zypper install playerctl
Void Linuxsudo xbps-install playerctl
NixOSAdd playerctl to environment.systemPackages

2. Check that it works

Start playing something in your media player, then run:

playerctl --list-all
playerctl status
  • The first command should list your player, for example spotify.
  • The second should print Playing or Paused.

If the first command prints nothing, your player does not support MPRIS, and MediaControl will not be able to see it either.

3. Start Minecraft

Launch the game with your music playing. The panel appears on the pause menu (Esc) and in the bottom-left of the main menu.

Using a Flatpak launcher (Prism Launcher, Modrinth App, etc.)

If your Minecraft launcher is installed as a Flatpak, it runs in a sandbox and cannot see playerctl on its own. Do both of the following:

  1. Install playerctl on your system (step 1 above).
  2. Allow the launcher to run commands on the host, using your launcher's Flatpak app ID:
flatpak override --user --talk-name=org.freedesktop.Flatpak org.prismlauncher.PrismLauncher

Common app IDs:

LauncherApp ID
Prism Launcherorg.prismlauncher.PrismLauncher
Modrinth Appcom.modrinth.ModrinthApp

Not sure of your launcher's ID? Run flatpak list and look it up. Restart the launcher after running the command.

MediaControl detects Flatpak automatically and runs playerctl on the host for you.

Troubleshooting

The panel says "No media playing"

Run playerctl --list-all in a terminal while your music is playing.

  • Empty output: the player does not support MPRIS, or it is not running in the same desktop session as the game.
  • playerctl: command not found: install it (step 1).
  • Works in the terminal but not in the game, and you use a Flatpak launcher: apply the Flatpak step above.

The album cover does not show

Make sure you are on the latest MediaControl release. Covers from players such as Spotify arrive as JPEG images, and older builds could not read them.

I use a remote or headless machine

The media player and Minecraft must run inside the same user desktop session.

Good to know

  • MediaControl starts one small helper process to talk to your media player. It reads only what is currently playing and sends play, pause, skip, back and seek commands. Nothing is sent over the network except downloading the current album cover image from the address your player gives.
  • Supported systems are Windows and Linux. macOS shows "Incompatible Operating System".
